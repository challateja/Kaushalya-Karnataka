# Contributing to Kaushalya Karnataka

First off, thank you for considering contributing to Kaushalya Karnataka! It's people like you who make this tool better for the workforce in Karnataka.

## How Can I Contribute?

### Reporting Bugs
* Check the GitHub Issues to see if the bug has already been reported.
* If not, open a new issue with a clear title and description, including steps to reproduce the bug.

### Suggesting Enhancements
* Open an issue with the tag "enhancement".
* Describe the feature and why it would be useful for the workers or users.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes (`./gradlew test`).
4. Make sure your code follows the existing style (Kotlin coding conventions).
5. Issue a pull request!

## Code of Conduct
Please be respectful and professional in all your interactions.
